Fab Path: Learn How Chips Get Made

A free, interactive platform teaching semiconductor fabrication from first principles, designed, written, and built solo, live today at fab-path.com.

Role Solo Designer & Developer
Scale 169 Lessons, 4 Courses
Stack Vanilla JS, Supabase
Status Live at fab-path.com

01 / OVERVIEW

Semiconductors are hard to learn from a textbook. I built a better way in.

While fabricating microsupercapacitors for my thesis, I kept noticing how little free, interactive material existed for people trying to learn semiconductor fabrication from the ground up. Most resources are either dense textbooks or paywalled courses.

Fab Path is my answer: illustrated lessons, custom vector diagrams, quizzes, and hands-on games, covering everything from how a chip is designed to how it is packaged and shipped. Every diagram, every question, and every line of code is mine.

02 / HOW IT WORKS

Learn it, play it, practice it.

Every unit follows the same loop, so learners spend their time on the parts they don’t know yet, not rereading what they’ve already mastered.

01 · Learn

Short illustrated lessons with cross-sections, curves, and worked equations.

02 · Play

Hands-on games: order a process flow, read a bias point, size a component.

03 · Practice

Practice sessions pull together the questions each learner gets wrong most.

03 / CONTENT AT SCALE

Four full courses, all written from scratch.

169

MEMS & Microfabrication (54 lessons), Supercapacitors (42 lessons, grounded in my own thesis research on 3D interdigitated glassy-carbon devices), and BioFETs & MOSFETs (25 lessons) round out the platform.

Every diagram is hand-built, inline SVG.

No stock art. Cross-sections, process flows, and equipment diagrams are all original vector graphics I authored to match exactly what each lesson explains, styled and animated with the site’s own design system.

05 / DESIGN ITERATION

40 slides before a single question was too many.

I originally built each unit of Sand to Chip as one long study module — around 40 slides — followed by a set of quizzes. Going through my own course, I found myself fatigued long before I reached a question, and realized learners would feel it too.

So I rebuilt it: every course on the platform now runs as many short units of about 6–8 slides, each one followed immediately by its own quiz, grouped into named “parts” for orientation. It touched course data, the learning-path renderer, the practice engine, and every existing unit page across all four courses.

BEFORE ~40 slides

One long module per unit, all the way through before any quiz.

AFTER 6–8 slides

Short units grouped into parts, each ending in an immediate quiz.

06 / UNDER THE HOOD

A static site that outgrew its own assumptions.

Fab Path is hand-written HTML, CSS, and JavaScript — no framework, no build step. It started as a purely client-side tool and grew a real backend only where a real need showed up.

Progress & Content Engine

Course structure, quiz banks, and per-unit diagrams live in plain JS data files. Streaks, XP, and completion are tracked in localStorage, so the site works fully offline with zero setup.

Cross-Device Sync

Optional email sign-in (one-time code or password) is backed by Supabase. Signing in merges the cloud copy with whatever progress already exists on the device, so switching devices never overwrites work.

Self-Hosted & Lightweight

Inter and JetBrains Mono are self-hosted, subset, and preloaded. Every diagram is inline SVG, not an image request, so pages stay fast.

Deployed & Indexed

Statically hosted on GitHub Pages at the custom domain fab-path.com, with a generated sitemap covering 361 URLs, Open Graph tags, and a canonical URL on every page.
